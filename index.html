🔥 Validation Status Heatmap

How to read this table

The Solutioning Status indicates the maturity of each User Story and whether it is ready for stakeholder review. It is automatically derived from the ADO State and Assigned To fields.

⚪ Not Started The User Story has not yet been picked up by the Salesforce team. No validation can be requested at this stage.
🔍 In ADO: State = New, any assignee.
🟠 In Progress The Salesforce team is actively designing the User Story. If validation is required, the item is not yet ready for review. Validation will be requested once the solution reaches a more stable state.
🔍 In ADO: State = In Design, any assignee.
🟡 Under Finalisation The Salesforce team is finalising the User Story after design. If validation is required, reviewers may already start providing feedback, understanding that minor updates or clarifications may still be introduced.
🔍 In ADO: State = Design Completed and assigned to a team member.
🟢 Finalised The Salesforce team has completed the User Story. If validation is required, the item is ready for stakeholder review and approval.
🔍 In ADO: State = Design Completed and unassigned — or any state beyond Design Completed (e.g. Ready to build, In Build, Ready for QA…).
💎 Best Effort This item is not part of the committed sprint scope. It will be delivered based on team bandwidth — if capacity allows, it will be completed within the sprint; otherwise it will roll over. Validation may be requested but is not guaranteed within the sprint timeline.
